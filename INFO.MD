# Social Network AI - Frontend

Этот проект представляет собой фронтенд-часть социальной сети, разработанную с использованием современных технологий и архитектурных подходов.

## Технологический стек

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Библиотека UI**: [React](https://reactjs.org/)
- **Язык**: [TypeScript](https://www.typescriptlang.org/)
- **Управление состоянием и API**: [TanStack Query](https://tanstack.com/query/latest) (React Query)
- **Работа с формами**: [React Hook Form](https://react-hook-form.com/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/) + [Sass (SCSS)](https://sass-lang.com/)
- **Контроль качества кода**: ESLint, Prettier, Stylelint
- **Инструменты**: Husky, lint-staged

## Архитектура

Проект следует методологии **Feature-Sliced Design (FSD)**. Основные слои в папке `src`:

- `app`: Инициализация приложения (провайдеры, глобальные стили).
- `pages`: Страницы проекта (композиция из виджетов и фич).
- `widgets`: Сложные компоненты, объединяющие фичи и сущности (например, шапка сайта, сайдбар).
- `features`: Пользовательские взаимодействия, несущие бизнес-ценность (например, "добавить в друзья", "создать пост").
- `entities`: Бизнес-сущности (User, Post, Comment) с их логикой и UI-компонентами.
- `shared`: Переиспользуемые компоненты и утилиты без привязки к бизнес-логике (UI-kit, API-клиенты, константы).

*Примечание: В корне есть также папка `app`, которая используется для маршрутизации Next.js App Router.*

## Инфраструктура

- **Docker**: Контейнеризация приложения (`Dockerfile`, `nginx.conf`).
- **CI/CD**: `Jenkinsfile` для автоматизации сборки и деплоя.
- **K8s**: `deployment.yaml` для развертывания в кластере Kubernetes.

## Основные команды

- `npm run dev` — запуск сервера разработки.
- `npm run build` — сборка проекта для продакшена.
- `npm run lint` — проверка кода линтерами.

## Как мы работаем

При работе над проектом:
1. Соблюдаем структуру **FSD**.
2. Используем **TypeScript** для типизации всего кода.
3. Логику работы с API выносим в соответствующие слои (entities/features) через **TanStack Query**.
4. Для стилизации используем комбинацию **Tailwind** и **SCSS Modules** (при необходимости).
5. Придерживаемся существующих конфигураций линтинга и форматирования.
