# Архитектурные и продуктовые решения

Здесь фиксируются согласованные решения: контекст, выбранный вариант, причины, последствия и дата. Заменённые решения сохраняются с указанием нового решения.

## Открытые вопросы

- Состав и критерии первой версии.
- Расположение и устройство бэкенда; модульный монолит — предложение для обсуждения, не принятое решение.
- Серверный стек, база данных, файловое хранилище и окружения.
- Совместимость с REST и выбор API для админки.
- Сессии, роли, OAuth, уведомления, платежи и необходимость переноса данных.

Согласованных решений по новой архитектуре пока нет.

## 2026-11-26: полный продукт небольшими PR

Владелец подтвердил полный объём функций. Работа идёт последовательно: инвентаризация, проектирование, затем небольшие PR с одной целью и проверяемым результатом. Выбор серверного стека и архитектуры остаётся открытым.
