# Документация проекта

Обновляйте документы вместе с изменением поведения. Состояние проекта — снимок настоящего; принятые решения сохраняйте с причиной и пометкой о замене. В «грабли» заносите воспроизведённые проблемы с проверкой, а предположения оставляйте в задачах до подтверждения.
