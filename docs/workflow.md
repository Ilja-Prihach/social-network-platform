# Рабочий процесс

Доска [Social Network Delivery](https://github.com/users/Ilja-Prihach/projects/2) показывает движение задач; репозиторий хранит долгоживущую документацию и [roadmap](roadmap.md). Представление «Работа» — канбан, «Весь план» — таблица. Начальные карточки являются черновиками: при уточнении работы их можно превратить в Issue репозитория.

## Стадии

1. **Идеи** — результат или границы ещё нужно уточнить.
2. **Готово к работе** — критерии приёмки понятны, зависимости для старта разрешены.
3. **В работе** — задача выполняется.
4. **Проверка** — результат проверяется или рассматривается pull request.
5. **Ждёт решения** — продолжение зависит от ответа владельца.
6. **Завершено** — результат проверен, связанные изменения и документация приведены в актуальное состояние.

Задачи описывают ожидаемый результат, критерии приёмки и зависимости. При изменении поведения обновляйте соответствующую документацию; при ошибке фиксируйте воспроизводимые факты и проверку исправления.

Для каждой задачи создавайте отдельную ветку от актуального `main`. Готовые и проверенные изменения коммитьте, отправляйте в эту ветку и открывайте pull request в `main`. Не коммитьте и не отправляйте изменения напрямую в `main`; слияние PR выполняйте по указанию владельца. Перед отправкой проверяйте состав изменений и результаты проверок; незавершённую работу не выдавайте за завершённую. Находки и результаты фиксируйте в соответствующих документах.

Заголовки и описания pull request пишем на русском языке.

Архитектурные варианты сначала обсуждаем с владельцем в разговоре; в PR фиксируем выбранное решение. Правила версий: [versioning.md](versioning.md).
