# Непрерывная интеграция

GitHub Actions запускает `CI / Checks` для каждого pull request и push в `main`. Проверка использует Node.js 24, устанавливает зависимости из корневого `package-lock.json` командой `npm ci`, затем запускает `npm audit --audit-level=high`, линтеры web и admin, stylelint и production-сборки обоих приложений. Предупреждения линтеров сами по себе не блокируют проверку; ошибки блокируют.

Для сборки admin задан тестовый локальный адрес `NEXT_PUBLIC_API_URL`: он не обозначает работающий бэкенд. CI не проверяет вход, работу API и сквозные сценарии и не выполняет развёртывание. Интеграционные проверки добавим, когда появится собственный бэкенд и окружение для него.

Секреты для текущих проверок не нужны. Устаревшие запуски того же PR отменяются при новом push. При настройке защиты `main` обязательной проверкой выбирается `Checks`; состояние защиты нужно проверять отдельно от самого workflow.
