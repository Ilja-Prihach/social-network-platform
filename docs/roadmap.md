# Roadmap

Порядок предварительный; состав этапов уточняется вместе с владельцем. Текущий статус — в [project-status.md](project-status.md), конкретные задачи и их движение — на [доске проекта](https://github.com/users/Ilja-Prihach/projects/2).

1. Определить продукт, первую версию и ограничения запуска.
2. Проверить локальный запуск и описать реальные контракты существующих интерфейсов.
3. Выбрать и подробно спроектировать архитектуру, модель данных, API и локальное окружение.
4. Разбить согласованный план на задачи с проверяемыми критериями.
5. Реализовать базовые сценарии аккаунта, профиля и постов в согласованном порядке.
6. Подключить админку и дополнительные возможности согласно приоритетам; проверить систему и подготовить запуск.

Полный объём продукта включает OAuth, уведомления, платежи, сообщения и остальные функции из [инвентаризации](feature-inventory.md). Реализация идёт небольшими PR; детали и необходимость переноса старых данных уточняются до соответствующего этапа.
