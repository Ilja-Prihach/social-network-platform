## Attribution notes

- Original author names, timestamps, commit messages, and merge relationships are retained.
- Author aliases are normalized with `.mailmap` for readable local statistics.
- Personal commit email addresses were replaced with the contributors' GitHub `noreply` addresses for privacy.
- History was rewritten only to remove environment files, generated build output, exposed configuration, and internal deployment files.

Run `git shortlog -sne HEAD` to inspect the contribution totals represented by the current branch.
